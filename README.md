# Mood Forge

Create a **premium, futuristic, highly realistic 3D food ordering website** inspired by the provided reference image. Do not simply recreate the mobile app UI as a flat website — transform the entire visual concept into an **immersive interactive 3D web experience**.

### CORE VISUAL DIRECTION

Build a luxury fast-food ordering website with:

* Dark cinematic background
* Premium black / charcoal glassmorphism
* Transparent frosted-glass cards
* Warm orange and amber accent lighting
* Realistic 3D food objects
* Soft volumetric lighting
* Subtle reflections
* Depth-of-field
* Realistic shadows
* High-quality HDR rendering
* Smooth GPU-accelerated animations
* Premium Apple-style product presentation
* Modern futuristic restaurant aesthetic

The website should feel like a combination of a **high-end 3D product website + premium food delivery platform**.

### HERO SECTION

Create a fullscreen immersive 3D hero section.

Place a huge realistic **3D juicy chicken burger** in the center/right of the screen.

Burger details:

On the left side display:

**Good Food**
**Good Mood!**

Below it:

"Fresh flavors. Bold cravings. Delivered your way."

Add two premium glass buttons:

Buttons should have:

* Glass surface

### 3D BURGER INTERACTION

Make the burger a real interactive 3D centerpiece.

Mouse movement should slightly rotate the burger.

Scroll interaction should:

* Rotate the burger
* Move the camera closer
* Reveal ingredients
* Create depth/parallax
* Change lighting dynamically

When the user clicks the burger, create a beautiful **ingredient explosion animation** where:

* Bun moves upward
* Cheese separates
* Lettuce separates
* Chicken patty moves slightly downward
* Tomato and onion become visible
* Sauce elements float between layers

Then smoothly assemble everything back together.

Keep the animation elegant and realistic, not cartoonish.

### DESIGN SYSTEM

Use:

* Background: near-black / charcoal
* Primary accent: warm orange
* Secondary accent: subtle amber
* Text: white / soft gray
* Cards: translucent dark glass
* Borders: subtle white transparency
* Border radius: 20–30px
* Soft shadows
* Realistic reflections
* Premium spacing
* Minimal clean typography

Do NOT use a generic restaurant template.

Do NOT make it look like a normal 2D food delivery website.

The final result must feel like a **next-generation 3D food commerce experience**.
